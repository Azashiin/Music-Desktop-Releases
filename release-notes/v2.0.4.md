## Français — Correction MusicDesktop Remote

- Corrige la disparition du morceau en cours dans l'application mobile après la mise à jour 2.0.3.
- Rétablit la transmission du titre, de la pochette, de la progression et de l'état de lecture au relais Remote.
- Préserve la compatibilité avec l'application mobile existante et les appairages déjà enregistrés.

Installez la mise à jour **sur le PC**, puis rouvrez Remote sur votre téléphone.
Téléchargez `Music.Desktop_2.0.4_x64-setup.exe` pour Windows 10/11 (64 bits), ou recherchez la mise à jour dans les paramètres de MusicDesktop.

## English — MusicDesktop Remote compatibility fix

- Fixes missing current-track information in the mobile application after the 2.0.3 update.
- Restores title, artwork, progress and playback-state updates to the Remote relay.
- Keeps compatibility with the existing mobile application and saved pairings.

Install this update **on the PC**, then reopen Remote on your phone.
Download `Music.Desktop_2.0.4_x64-setup.exe` for Windows 10/11 (64-bit), or check for updates in MusicDesktop settings.
