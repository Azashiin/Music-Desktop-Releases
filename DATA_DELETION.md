# MusicDesktop Remote — Data Deletion

MusicDesktop Remote does not use user accounts.

The application may store technical data required for device pairing, such as:
- mobile device identifier;
- MusicDesktop device identifier;
- pairing and authorization information.

To delete the data associated with your device:

1. Open MusicDesktop Remote.
2. Open Settings.
3. Select "Unlink this device".

This revokes the device authorization and removes the pairing association.
